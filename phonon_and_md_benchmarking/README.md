# Phonon and Molecular Dynamics Benchmarking

Cross-engine phonon dispersion evaluations and finite-temperature (300 K NPT)
molecular dynamics stability assessments across the benchmark polymorphs of
$\ce{LiF}$, $\ce{CsPbI3}$, $\ce{HfO2}$, and $\ce{Bi2Sn2O7}$, corresponding to
Table 1 and Supplementary Tables S4, S7, S8, S9, and S10.

## Directory Naming Conventions

- `MACE_evals/`, `MACEMP_evals/`, `ESEN_evals/`, `UMA_evals/` — static
  relaxation and phonon evaluations for each engine. Each subfolder is named
  `EVAL_cifs_<batch>_<engine>_<structure_id>_<ENGINE>_phonon_output_<timestamp>/`
  and contains:
  - `initial_relaxation_for_single_run/` — relaxed CIF (`*_relaxed.cif`),
    symmetry analysis (`initial_symmetry_analysis.txt`,
    `relaxed_symmetry_analysis.txt`), and relaxation energy (`energy_info.txt`).
  - `N<supercell>_D<delta>_F<fmax>/` — phonon band structure arrays, DOS curves,
    `special_point_analysis.json`, and summary report (`*_phonon_run_summary.txt`).
- `MACE_MD_evals/`, `MACEMP_MD_evals/`, `ESEN_MD_evals/`, `UMA_MD_evals/` —
  finite-temperature NPT molecular dynamics runs (`--method md_stability`,
  300 K, 10 ps). Each subfolder contains `md_stability_analysis/` with RMSD,
  volume fluctuation, RDF correlation, and symmetry-retention reports and plots.

## Summary Tables and Scripts

- `vibroml_master_eval_summary.csv` — consolidated phonon evaluation table
  generated by `extract_evals_all.py`.
- `vibroml_master_md_summary.csv` — consolidated MD stability table generated
  by `extract_md_evals_all.py`.
